The model comparison table summarizes each classifier using ROC-AUC, accuracy, precision, recall, and F1-score. Since serious delinquency is an imbalanced outcome, accuracy alone is not enough to evaluate model performance. Recall, precision, F1-score, and ROC-AUC provide a more useful picture of how well the models identify loans that become 90 or more days past due.

Logistic regression was used as the interpretable baseline model. The coefficients show the direction and strength of association between each feature and the odds of serious delinquency. Positive values increase the predicted odds of 90+ day delinquency, while negative values decrease the predicted odds.

Because the logistic regression model used standardized numeric variables, the coefficient interpretations are based on changes in the standardized feature scale. This makes the coefficients useful for comparing relative influence across variables, but they should not be read as raw one-unit changes in the original data.

Histogram Gradient Boosting was included because it can capture nonlinear patterns and interactions between borrower, loan, and property characteristics. Its importance values come from permutation importance, which measures how much model performance drops when a variable is shuffled. A larger drop means the model relied more heavily on that variable.
